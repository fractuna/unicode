A python project (mostly in jupyter) to learn/work with AI models and Machine Learning. This project works in conjunction with my AI-Lab class. You can find related references in this project inside my notes (https://fractuna.github.io).

# How to run

Simply use _uv_ tool to run this project. Because this project is _Jupyter notebook_ heavy, then you should do:

```
uv run jupyter lab
```

I personally use _Ipython_ while I'm using Jupyter for extra scripting and learning. You can run it by:

```
uv run ipython
```
